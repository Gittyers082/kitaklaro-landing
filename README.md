# KitaKlaro
The official repository for Team parZval in the PinaSiklab Hackathon (Track 3: MSMEs).

A showcase landing page for the problem we are solving: sari-sari stores and
Public Market stalls in Baguio keep their records in a notebook that cannot
track stock, warn before items run out, or produce a report a bank or the BIR
will accept.

The site lives in [`web/`](web/README.md) (Next.js, static export).

```bash
cd web
npm install
npm run dev        # http://localhost:3100
```
